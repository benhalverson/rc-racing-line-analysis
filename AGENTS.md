## Agent skills

### Issue tracker

GitHub Issues via `gh`; external pull requests are not a triage request surface. See `docs/agents/issue-tracker.md`.

### Triage labels

Uses the canonical `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, and `wontfix` labels. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context layout with root `CONTEXT.md` and `docs/adr/`. See `docs/agents/domain.md`.
